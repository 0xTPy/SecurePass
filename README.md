# SecurePass

SecurePass est un programme Python qui vous permet de vérifier si votre mot de passe est difficile à craquer et de générer des mots de passe sécurisés.

             ||INSTALLATION||


git clone https://github.com/0xTPy/SecurePass.git
cd SecurePass

             ||UTILISATION||


python securepass gen -long 15
python securepass verif "votre_mot_de_passe"
python securepass -h
EXPLICATION
gen -long 15 : Permet de générer un mot de passe avec une longueur personnalisable. Dans cet exemple, la longueur est fixée à 15.
verif : Permet de vérifier la sécurité de votre mot de passe.
-h : Affiche l'aide et les commandes disponibles.
